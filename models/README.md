# Models Directory

This directory contains model files for the AI attendance system.

## Structure

```
models/
├── scrfd/       # SCRFD face detection models
├── arcface/     # ArcFace face recognition models
├── landmark/    # Facial landmark models (1k3d68)
├── reid/        # ReID (Re-Identification) models
└── yolo/        # YOLO object detection models
```

## Important

- Do NOT download models automatically in this phase.
- Do NOT copy old models automatically.
- The exact model registry will be implemented in PHASE 2.
- Each subdirectory is prepared but should remain empty until PHASE 2.
